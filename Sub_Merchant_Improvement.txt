Sequence Diagram: Import Sub Merchant Perorangan / Badan Usaha (3 sistem: Merchant App, Paydia Backend, Storage)
sequenceDiagram
    actor Merchant
    participant App as Web Merchant
    participant Backend as Paydia Backend
    participant Storage as File Storage
 
    Merchant->>App: Klik Unduh Template Perorangan / Badan Usaha
    App->>Backend: Request template file Perorangan / Badan Usaha
    Backend-->>App: Response file template .xlsx
    App-->>Merchant: File template terunduh
 
    Merchant->>App: Upload file template yang sudah diisi
    App->>Backend: Kirim file template untuk validasi
    Backend->>Backend: Validasi format, jumlah entri, nilai kolom per baris
    Backend-->>App: Response hasil validasi per baris (Valid / Tidak Valid + keterangan)
    App-->>Merchant: Tampil tabel preview dengan status validasi per baris
 
    alt Ada baris tidak valid
        Merchant->>App: Perbaiki file & upload ulang
        App->>Backend: Kirim file template baru
        Backend-->>App: Response validasi ulang
        App-->>Merchant: Tampil tabel preview diperbarui
    end
 
    loop Untuk setiap sub merchant
        Merchant->>App: Upload dokumen per sub merchant Perorangan / Badan Usaha
        App->>Storage: Simpan file dokumen sementara
        Storage-->>App: Konfirmasi file tersimpan
        App-->>Merchant: Indikator dokumen baris = lengkap
    end
 
    Merchant->>App: Klik tombol Kirim
    App->>Backend: Kirim data import + referensi file dokumen
    Backend->>Storage: Pindahkan file dokumen ke storage permanen
    Storage-->>Backend: Konfirmasi file tersimpan permanen
    Backend->>Backend: Proses registrasi sub merchant perorangan secara batch
    Backend-->>App: Response sukses + Batch ID
 
    alt Proses gagal (server error)
        Backend-->>App: Response error
        App-->>Merchant: Tampil pesan gagal, coba lagi
    else Proses berhasil
        App-->>Merchant: Notifikasi sukses, pindah ke Riwayat Import
    end
